# GyroVR

## Overview

| 항목 | 내용 |
| --- | --- |
| 형태 | 지니소프트 GCC사관학교 3기 기업연계 프로젝트 |
| 기술 | Unreal Engine, C++, Blueprint, Sequencer, Unreal Python |
| 담당 작업 | 차량 경로 추종, 속도 편집 도구, 추격 연출과 자동화 |
| 상세 페이지 | [GyroVR 기술 포트폴리오](../website/projects/gyrovr/index.html) |

## Summary

차량 경로 추종 로직을 C++ 플러그인으로 분리하고, 스플라인에서 구간 속도를 편집하는 도구를 만들었습니다. 시퀀서에서는 추격차 7대의 등장·추월·충돌 타이밍을 조정했습니다.

## Problem

경로 추종에서는 중첩 구간의 목표점 오선택과 조향 진동이 발생했습니다. 장면 제작에서는 경로 변경 뒤 차량 이동과 거리 키가 어긋나 추격 타이밍을 다시 맞춰야 했습니다.

## Implementation

진행 거리를 기준으로 목표점을 선택하고 속도에 따라 목표점 거리를 조절했습니다. 자동차·레일·드론의 Follow 컴포넌트를 구분하고 마스터가 전환 순서를 관리하도록 설계했습니다.

이후 시네마 차량·시퀀서 방식으로 주행 애니메이션을 전환했습니다. Unreal Python으로 추격차 7대의 스플라인과 거리 키를 다시 적용하고 플레이 테스트로 속도와 차 간격을 검수했습니다.

## Contribution

- SplineFollowVehicle C++ 플러그인 분리와 아트팀 사용 문서 전달
- 스플라인 속도 마커, 시각화와 에디터 프리뷰
- 목표점 선택, 모드 전환 중 물리 상태, 닫힌 루프 Tick 오류 수정
- 시퀀서 추격 연출과 차량 BP의 노면 보정
- Python을 이용한 7대의 경로·거리 키 재적용
- 접촉 키 323개에서 100개로 정리

## Scope

완성 영상은 팀 결과물입니다. 키 개수 감소는 트랙 정리 결과이며 런타임 성능 측정값은 아닙니다. 8월의 주행 플러그인 C++ 전환과, 9월 시험 후 중단한 차량 BP 이전 작업은 구분합니다.
