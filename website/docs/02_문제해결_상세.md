# GyroVR 문제 해결 사례

면접에서는 현상과 원인을 먼저 설명하고, 실제로 바꾼 부분과 확인한 결과를 이어서 말합니다. 아래 사례의 구체적인 함수명과 코드 위치는 저장소를 확인한 뒤 보강할 수 있습니다.

## 겹친 경로에서 목표점 선택

경로가 겹치는 구간에서 차량이 지나온 구간이나 다른 커브를 목표로 잡았습니다. 목표점 선택을 진행 거리 기준으로 처리해 문제를 해결했습니다. 같은 날 좌우 조향이 반복되어 궤적이 물결치는 현상은 속도에 따른 목표점 거리 조정으로 개선했습니다.

이 사례에서는 경로의 공간적 위치만으로는 진행 순서를 구분하기 어려운 조건을 설명할 수 있습니다. 실제 탐색 범위, 보간식, 예외 처리 방식은 코드 확인 없이 임의로 덧붙이지 않습니다.

근거: 8월 13일 활동일지.

추가할 증거: 경로 중첩 구간의 디버그 화면, 현재 진행 거리와 목표점 표시, 수정 전후 같은 구간의 주행 영상, 해당 목표점 선택 코드.

## 모드 전환 뒤 바퀴와 서스펜션 이상

레일에서 자동차 모드로 복귀하면 바퀴 본과 서스펜션이 비정상적으로 보였습니다. 콜리전을 해제하는 과정에서 물리 상태가 재생성되는 것이 원인임을 확인해 해결했습니다. 플러그인 v0.1.2와 사용 문서를 함께 커밋했습니다.

회전이나 위치값을 조정하기 전에 모드 전환 중 발생하는 물리 상태 변화를 확인했다는 점을 중심으로 설명합니다. 일지에는 정확한 수정 API가 없으므로 함수명과 호출 순서는 코드로 확인해야 합니다.

근거: 8월 19일 활동일지.

추가할 증거: 모드 전환 전후의 바퀴 상태, 물리 상태 재생성과 관련된 호출부, 수정 커밋.

## 두 번째 주행에서 모드 전환 중단

닫힌 경로의 첫 주행에서는 동작하던 모드 전환이 두 번째 주행부터 실행되지 않았습니다. 마지막 전환을 소비한 뒤 컴포넌트가 스스로 Tick을 종료하고 있었습니다. 닫힌 루프에서는 Tick을 유지하도록 수정했습니다.

모드 전환 기능 하나만 확인하는 테스트로는 반복 재생 상태의 오류를 놓칠 수 있었습니다. 한 바퀴를 마친 뒤에도 갱신과 전환이 계속되는지를 확인해야 하는 사례입니다.

근거: 8월 31일 활동일지.

추가할 증거: 닫힌 경로를 두 바퀴 이상 도는 영상, 전환 소비 상태와 Tick 상태를 표시한 로그, 조건 분기 코드.

## 경로 변경 후 추격차 타이밍 재구성

히어로 경로 변경과 잘못 저장된 거리 키로 차량 이동이 어긋났습니다. 원인을 확인해 임시 복구하고, 차량별 등장·추월 순서와 교대 몸싸움·협공 장면을 표로 정리해 재구축 기준을 만들었습니다.

다음 날 Unreal Python으로 추격차 7대의 스플라인과 시퀀서 거리 키를 다시 적용했습니다. 장애물 회피와 자리싸움 경로를 수정하고, 옛 접촉 섹션 21개를 비활성화했습니다. 플레이 테스트로 속도와 차 간격을 확인했습니다.

이 작업은 재적용 자동화 사례입니다. 실행 시간이나 수동 작업 대비 절감 시간은 측정 기록이 없어 성과 수치로 넣지 않습니다.

근거: 9월 21일·22일 활동일지.

추가할 증거: 장면표, Python 입력과 출력, 재적용한 시퀀서 트랙, 적용 전후 차량 배치.

## 스플라인 편집 UI 확장

속도 마커 UI를 추가하려고 스플라인 컴포넌트의 Details UI를 전역 교체했을 때 시네마 스플라인의 기본 UI까지 덮어썼습니다. 기본 UI를 먼저 유지한 뒤 마커 UI만 덧붙이는 방식으로 수정했습니다.

기능을 확장하는 과정에서 다른 편집 도구에 영향을 준 사례입니다. 사용자에게 필요한 기본 편집 기능을 유지하면서 새 속성만 추가한 기준을 설명할 수 있습니다.

근거: 8월 21일 활동일지.

추가할 증거: 기본 UI가 사라진 상태와 복원한 상태, 커스터마이징 등록 범위, 최종 속도 마커 패널.

## 노면 보정과 추격 장면 편집

스플라인 높이와 차량 크기가 맞지 않는 구간에서 관통과 바퀴 부양을 점검했습니다. 차량 BP에 라인 트레이스 높이 보정을 넣고 네 바퀴 높이 보정과 노면 선택을 개선했습니다. 시퀀서에서는 접촉 키를 323개에서 100개로 줄였습니다.

네 바퀴 보정 적용과 Modify Bone을 이용한 서스펜션 시험은 구분합니다. 접촉 키 감소는 트랙 정리 결과이며, FPS 향상을 증명하지 않습니다.

근거: 9월 9일·11일·14일·17일 활동일지.

추가할 증거: 네 바퀴 트레이스 표시, 보정 전후 접지 상태, 정리 전후 키 개수 화면.
