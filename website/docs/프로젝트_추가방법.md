# 프로젝트 추가 방법

메인 페이지의 내용은 assets/js/content.js에서 관리합니다. projects 섹션의 items에 프로젝트를 추가합니다.

```js
{
  id: 'next-project',
  name: '프로젝트 이름',
  company: '소속 또는 프로젝트 유형',
  role: '내 담당 작업',
  desc: '프로젝트와 기여를 두세 문장으로 설명합니다.',
  tech: ['Unreal Engine', 'C++'],
  preview: {
    poster: 'assets/images/프로젝트대표이미지.jpg',
    video: 'assets/video/프로젝트영상.mp4',
    caption: '영상 미리보기'
  },
  href: 'projects/next-project/index.html'
}
```

상세 페이지는 projects/프로젝트ID/index.html로 만듭니다. 현재 GyroVR 상세 페이지는 assets/js/gyrovr-detail.js의 내용을 사용합니다. 각 상세 페이지는 독립된 content 파일을 읽도록 구성하면 됩니다. 메인 페이지의 긴 사례는 project-index.js에서 출력하지 않고, 상세 페이지는 기존 app.js의 사례 렌더러를 사용합니다.
